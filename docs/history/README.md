# History

Three write-ups from the first build of Earful, kept as they were written. The work went
in stages, and each stage closed with a page that states what was measured. The pages
call a stage a gate.

| Page | The question it answers | Written |
| --- | --- | --- |
| [`gate0-feasibility.md`](gate0-feasibility.md) | Can a real LiveKit `AgentSession` be run deterministically? | 14 November 2026 |
| [`gate1-core.md`](gate1-core.md) | Is the core complete? | 16 November 2026 |
| [`gate2-historical-proof.md`](gate2-historical-proof.md) | Do known defects show up, and go away where they were fixed? | 16 November 2026 |

These pages are not kept up to date. A script, a command or a number in one is as it was
when the page was written, and the code has moved since: the first page names scripts
that were renamed. The pages one directory up describe Earful as it is.
`gate0/evidence/` holds the raw output of the first stage.
